فتح نظام الفواتير الكامل
لإنشاء فاتورة لعميل: اذهب لتبويب «العملاء»، اضغط أيقونة «إنشاء فاتورة» (المستند) بجانب العميل. سيتم تحويلك تلقائياً إلى نظام الفواتير وملء بياناته.

إعداد قاعدة البيانات (Supabase)
مطلوب إعداد لمرة واحدة فقط — للسماح بتعديل قاعدة البيانات مباشرة من لوحة التحكم (إضافة/تعديل/حذف عملاء):
  1. أنشئ حساباً مجانياً على supabase.com وأنشئ مشروعاً جديداً
  2. من القائمة الجانبية: SQL Editor → New query
  3. الصق محتوى ملف supabase_schema.sql كاملاً واضغط Run
  4. من Project Settings → API انسخ:
      • Project URL
      • service_role secret key (ليس anon!)
  5. في Netlify → Site settings → Environment variables أضف:
      • SUPABASE_URL = Project URL
      • SUPABASE_SERVICE_KEY = مفتاح service_role
      • INVOICE_PASSWORD = رمز الأمان (موجود مسبقاً)
  6. أعد نشر الموقع (Deploy) — اضغط زر «إعادة الفحص» بالأسفل للتحقق
